AgenticWeightInfra

Program a language model by editing its weights, not its prompt. A few lines of code compile into WebGPU compute passes that rewrite the parameters: merges, ablations, noise, concept injection. An agent can write that program, probe the edited model, and revise the strength. WebLLM loads the result in the same tab. Nothing leaves your machine.

Language reference

<selector> <op> [args], one rule per line. Rules apply in order.

Selectors: * · embed · layers.10-13 · layers.*.mlp · layers.*.attn.o_proj · layers.0-5.*norm

Ops: mix a w += a·(donor − base) · scale k · zero · noise s · skip (zero o_proj + down_proj) · zero-heads 0-6 · inject word c (solve value-bias deltas so the layer writes c·unit(E[word]) into the residual stream) · steer concept c (rank-one down_proj edit from a vector pack)

Agent

Observe the tensors, write a weight program, probe both models, and revise only the coefficient. A merge is refused when the weight matrices are not in one linear basin.

Change control

Policy 2026.1 gates every build and every agent probe. A routine edit needs an operator and a reason. A review-level edit also needs approval. A denied edit does not run. The decision stays in the audit log on this machine.
