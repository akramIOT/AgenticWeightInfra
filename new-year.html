Language reference

<selector> <op> [args], one rule per line. Rules apply in order.

Selectors: * · embed · layers.10-13 · layers.*.mlp · layers.*.attn.o_proj · layers.0-5.*norm

Ops: skip (zero o_proj + down_proj) · zero-heads 0-15 · noise s · scale k · zero · steer concept c (rank-one edit of mlp.down_proj from a vector pack) · mix a w += a·(donor − base) · inject word c (needs attention value biases; this model has none)

Change control

Policy 2026.1 gates every build and every agent probe. Lab allows a routine edit with an operator and a reason. A review-level edit also needs a ticket and a different approver. Controlled runs only an approved program, and it holds injection, steering, and noise for that approval. A denied edit does not run.
